# Tatos: avance y punto de retoma al 11 de noviembre de 2026

Este archivo conserva las decisiones y el avance de la conversación hasta hoy.
Es un resumen para continuar el trabajo, sin transcribir información personal,
credenciales, códigos de autenticación ni enlaces de invitación.

## Alcance de este guardado

La propietaria pidió guardar en GitHub el trabajo hasta la conversación de hoy.
El destino es la rama `preview/render-2026-11-06` de Tatos, separada de `main`.
Guardar el código no despliega la aplicación. El servicio de prueba tiene el
despliegue automático desactivado, comprobado el11/11. No se solicitó un nuevo
despliegue, una fusión a producción ni operaciones reales con los proveedores.

## Decisiones que se mantienen

- Cada consultorio conecta sus propias redes mediante el inicio de sesión del
  proveedor, sin compartir contraseñas ni dar acceso de administración de Tatos.
- RUC e ID empresarial son datos declarados: no sustituyen la autorización de
  Meta, sus roles de desarrollo o la habilitación de los permisos correspondientes.
- Cada persona pertenece a un solo grupo de publicidad. Las campañas y diseños
  generados requieren revisión; los datos clínicos no se usan para publicidad.
- Cobros por consultas/citas pertenecen a cada consultorio. La suscripción de la
  plataforma es otra obligación, con precio solicitado de USD100 mensuales.
- Recordatorios de pago: cada día después del vencimiento, máximo tres. La
  implementación de pruebas no acredita mensajes ni cobros reales.
- Tests en imagen deben conservar parámetros, fuente, versión y revisión de las
  respuestas detectadas. No se consideran clínicamente validados los resultados
  sintéticos ni se inventan baremos. Se necesitan las fuentes autorizadas de cada test.
- Las pruebas manuales se realizan en Chrome y avanzan un control a la vez.

## Trabajo disponible en la rama

La base anterior ya contiene el laboratorio protegido, flujos de pacientes/equipo,
agenda compartida y reprogramación, fuentes de Tests, marketing, encuestas, saldos
y ensayos fiscales. El entorno Render de prueba utiliza datos ficticios y base en
memoria; se pierden al reiniciar. Meta, WhatsApp, pagos y SRI no se prueban de forma
real allí. La visión local tampoco está habilitada en ese Render.

El avance nuevo añade **Ajustes → Integraciones del consultorio**:

- Meta: RUC e ID del portafolio empresarial, con enlace al OAuth existente.
- TuFacturero: RUC y referencia de cuenta opcional, pendientes del contrato API.
- MentalTestLab: referencia de cuenta, pendiente de confirmar el contrato API.
- Datos propios por consultorio, cifrados; lectura/escritura para Administración
  o Dueña, revisión por versión y eliminación de las referencias.
- Migración `0038_integration_setup`, después de `0037_tax_trials`.
- Estados de preparación que no presentan una autorización externa como verificada.

Las referencias no contienen contraseñas ni claves API. No se han inventado
endpoints de proveedores ni conectado una cuenta real a través de este módulo.

## Evidencia comprobada

Para esta ampliación, la ejecución local del10/11 terminó con **67 pruebas
aprobadas, una omitida y cero fallos**. Incluyó API/permisos, cifrado, aislamiento
entre consultorios, migraciones SQLite, OAuth simulado y recorrido en Chrome.
La omisión corresponde al bloqueo asesor de migraciones concurrentes, específico
de PostgreSQL. No hay prueba nueva de PostgreSQL real o proveedores reales.

Antes de este guardado se repitió la misma selección el11/11: **67 aprobadas,
una omitida y cero fallos**, en57,63s. El test de navegador usa Chrome en Windows
y el Chromium instalado por la configuración existente de CI en Linux. Los diez
archivos Python nuevos/modificados pasan Ruff, incluido el formato. El escaneo
Gitleaks del árbol de trabajo no encontró secretos; omitió únicamente carpetas
de caché de pytest sin permiso de lectura, que no se incluyen en el commit.

Chrome comprobó guardar, recargar y eliminar referencias, ancho móvil390px y
ausencia de errores JS/solicitudes externas. Ruff de los diez archivos Python y
mypy de177 fuentes aprobaron; sintaxis JS y revisión de espacios Git aprobaron.
No se atribuye esta evidencia local al servicio publicado.
