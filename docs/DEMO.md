# MVP demo in GitHub Codespaces

The demo is a synthetic psychology practice in which every flow runs end to end through the real API. All the data is invented: names, 555 phone numbers, example.test e-mails. Never load real patients into a demo.

## 1. One-time setup: about 5 minutes

1. **Codespaces secrets.** On GitHub go to Settings → Codespaces → Secrets, and give each one access to the repository:
   - `ANTHROPIC_API_KEY`: needed for real answers from Claude. Without it, the offline model gives canned answers, and every flow still runs.
   - `TELEGRAM_BOT_TOKEN` (optional): create a bot with @BotFather and paste its token.
   - `TELEGRAM_CHAT_ID` (optional): your own chat id. Send any message to your bot, then open `https://api.telegram.org/bot<TOKEN>/getUpdates` and read `message.chat.id`. With these two set, the engagement campaign is sent **live** to you, and only to you.
2. **Start the codespace.** In the repository go to Code → Codespaces → Create codespace on main. It takes about 3 minutes, installs everything and prints "Ready".

## 2. Run it

```bash
bash scripts/demo-codespaces.sh
```

The script:
- starts Postgres 17 and Qdrant;
- starts the API on port 8000;
- seeds the practice and walks every flow, printing a report and one key per role.

To open the console, use the **Ports** tab → port 8000 → globe icon, then paste a key into the "API key" box.

| Key | What to try |
|---|---|
| `recepcion` | Ask "¿Cuál es la política de cancelación?": answered from the practice's FAQ. Ask about a medication dose: held for review. |
| `dra.vera` | **Reviews** tab: the held answer; edit it and approve it. The receptionist's page updates by itself, labelled "Edited and approved by a professional". |
| `direccion` | API docs at `/docs`: insights, campaign results, audit, data-subject export and erasure. |
| `paciente` | `GET /v1/me`, `POST /v1/me/chat`: the patient's own appointments and chat. |

## 3. What each flow shows

| Flow | Status in the demo |
|---|---|
| Team, roles, professionals with their own packs | ✅ live |
| 20 patients, visits, plans, consents | ✅ live (synthetic) |
| Clinical record: session note, psychotherapy note (author only) | ✅ live |
| **Tests designed by the psychologist** (items, reverse scoring, subscales, bands, alerts, versions); PHQ-9 and GAD-7 templates | ✅ live: `POST /v1/clinical/instruments`, results at `/v1/clinical/patients/{id}/instrument-results` |
| **Document management**: signed consent PDF, SHA-256, audited download | ✅ live: `/v1/clinical/patients/{id}/files` |
| Assistant with company knowledge; clinical answers held for a human | ✅ live (Claude with the key) |
| **Engagement campaign** with a control group, approval, sending, results | ✅ live on Telegram with token and chat id; otherwise a rehearsal (nothing sent) |
| **Social media:** Instagram, TikTok, WhatsApp, Telegram accounts; creatives generated by code; approval; publishing | Telegram ✅ live with a token. Instagram, TikTok and WhatsApp: **dry run**, which records the exact request and sends nothing, until each account's credentials are added as `SOCIAL_SECRET_<REF>`. Facebook: **refused** until its publishing rules are verified (decision A6) |
| Crisis message on WhatsApp → alert to the on-call professional | ✅ live (signed webhook) |
| Data-subject export and erasure, hash-chained audit verified | ✅ live |

## 4. Going live on each network (needs the owner's accounts)

| Network | What you need | Typical time |
|---|---|---|
| Telegram | A bot from @BotFather | 2 minutes |
| WhatsApp | A Meta Business account, a WhatsApp Business number, an app with the WhatsApp product (Meta's test number works for development), and an approved template for staff alerts | days |
| Instagram / Facebook | A professional account linked to a Page; a Meta app with publishing permissions (development mode publishes for app testers; App Review is needed for everyone else); media on a public URL (creatives bucket) | days to weeks |
| TikTok | A developer app; until TikTok audits it, posts are private | weeks |

Add each credential as the secret named by the account's `secret_ref`, for example `SOCIAL_SECRET_IG_DEMO`. The code does not change.

## 5. Stop

```bash
kill $(cat .demo/api.pid); docker compose stop postgres qdrant
```
