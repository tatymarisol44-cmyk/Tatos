# MVP demo in GitHub Codespaces

The demo is a synthetic psychology practice in which every flow runs end to end through the real API. All the data is invented: names, 555 phone numbers, example.test e-mails. Never load real patients into a demo.

## 1. One-time setup: about 5 minutes

1. **Codespaces secrets.** On GitHub go to Settings → Codespaces → Secrets, and give each one access to the repository:
   - `ANTHROPIC_API_KEY`: needed for real answers from Claude. Without it, the offline model gives canned answers, and every flow still runs.
   - `TELEGRAM_BOT_TOKEN` (optional): create a bot with @BotFather and paste its token.
   - `TELEGRAM_CHAT_ID` (optional): your own chat id. Send any message to your bot, then open `https://api.telegram.org/bot<TOKEN>/getUpdates` and read `message.chat.id`. With these two set, the engagement campaign is sent **live** to you, and only to you.
2. **Start the codespace.** In the repository go to Code → Codespaces → Create codespace on main. It takes about 3 minutes, installs everything and prints "Ready".

## 2. Run it

```bash
bash scripts/demo-codespaces.sh
```

The script:
- starts Postgres 17 and Qdrant;
- starts the API on port 8000;
- seeds the practice and walks every flow, printing a report and one key per role.

To open the console, use the **Ports** tab → port 8000 → globe icon, then paste a key into the "API key" box.

| Key | What to try |
|---|---|
| `recepcion` | Ask "¿Cuál es la política de cancelación?": answered from the practice's FAQ. Ask about a medication dose: held for review. |
| `dra.vera` | **Reviews** tab: the held answer; edit it and approve it. The receptionist's page updates by itself, labelled "Edited and approved by a professional". |
| `direccion` | API docs at `/docs`: insights, campaign results, audit, data-subject export and erasure. |
| `paciente` | `GET /v1/me`, `POST /v1/me/chat`: the patient's own appointments and chat. |

## 4. Going live on each network

Add these as **Codespaces secrets**, then run the script again. The code does not change.

| Network | Secrets | Where to get them |
|---|---|---|
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | @BotFather → `/newbot`; your chat id from `https://api.telegram.org/bot<TOKEN>/getUpdates` |
| WhatsApp | `WHATSAPP_PHONE_NUMBER_ID`, `SOCIAL_SECRET_WA_DEMO`, `META_APP_SECRET`, `WHATSAPP_VERIFY_TOKEN` | developers.facebook.com → create a Business app → add **WhatsApp** → API Setup gives a free **test number**, its *phone number id* and a token; add your own phone as a recipient. App settings → Basic → *App secret*. The verify token is any word you choose. After the script runs, paste the printed **Callback URL** and verify token in WhatsApp → Configuration → Webhook, and subscribe to `messages` |
| Instagram | `INSTAGRAM_USER_ID`, `SOCIAL_SECRET_IG_DEMO` | A professional Instagram account linked to a Facebook Page; the same Meta app with the Instagram publishing permission (development mode works for your own account). Images are fetched from the Codespace's public, signed URLs |
| Facebook Page | `FACEBOOK_PAGE_ID`, `SOCIAL_SECRET_FB_DEMO` | A **Page** access token with `pages_manage_posts`, `pages_read_engagement` and `pages_show_list` (Graph API Explorer → your app → Get Page Access Token). The image is uploaded with the request |
| TikTok | `TIKTOK_ACCOUNT_ID`, `SOCIAL_SECRET_TT_DEMO` | developers.tiktok.com → app with Content Posting (`video.publish`). Until TikTok audits the app, posts are private |

When a Meta channel is configured, the script makes port 8000 **public**: Meta must reach it. Every API route still needs a key, and media URLs are signed and expire.

## 5. Stop

```bash
kill $(cat .demo/api.pid); docker compose stop postgres qdrant
```
