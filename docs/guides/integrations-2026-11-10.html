Conexiones de cada consultorio

Preparación local del 10 de noviembre de 2026. La pantalla nueva aún no está publicada en Render. Las conexiones externas no se han activado.

Qué está preparado

La pantalla Ajustes → Integraciones del consultorio → Preparar integraciones permite a Administración o Dueña guardar y eliminar las referencias de su empresa. Cada consultorio tiene sus propios datos. El formulario no recibe contraseñas ni claves API.

Las comprobaciones locales finalizaron con 67 pruebas aprobadas y una omitida. Se revisaron los formularios en Chrome, el aislamiento entre consultorios, permisos, cifrado, conflictos al guardar y migración de base de datos SQLite. No es evidencia de conexión real.

1. Facebook, Instagram y WhatsApp

  1. En la nueva sección, escribir el RUC de la empresa y el ID del portafolio empresarial de Meta.
  2. Pulsar Guardar datos de mi cuenta. El estado seguirá indicando verificación externa pendiente.
  3. Pulsar Continuar con el inicio de sesión de Meta.
  4. Elegir la red, iniciar sesión en Meta y autorizar los activos que administra ese consultorio.
  5. Al volver a Tatos, elegir la cuenta autorizada para terminar de vincularla.

Un RUC o un ID no otorga un rol de prueba ni verifica la propiedad de una cuenta. La habilitación de usuarios externos depende de Meta y de los permisos concretos de la aplicación. No se ha abierto el modo desarrollo a todas las cuentas.

Referencias oficiales de Meta: Marketing API y acceso avanzado; permisos de conversaciones.

2. TuFacturero

Se pueden preparar el RUC y una referencia de cuenta. TuFacturero confirma que dispone de API, pero falta obtener su documentación y acceso técnico para implementar y probar el conector.

  1. Entrar en la cuenta propia de TuFacturero.
  2. Solicitar a su equipo de desarrollo documentación de integración y ambiente de pruebas.
  3. Pedir autenticación por empresa, emisión, consulta de estados, XML/RIDE y prevención de duplicados.
  4. Guardar las credenciales por un canal privado cuando el contrato esté disponible.

La preparación no emite una factura ni acredita autorización del SRI. Respuesta oficial de integración.

3. MentalTestLab

Se puede guardar una referencia de cuenta. No se encontró documentación pública de API en la búsqueda realizada. El enlace de CAPTCHA no es una API de evaluaciones.

  1. Abrir el catálogo oficial de evaluaciones.
  2. Consultar si ofrecen API para integrar cuentas de consultorios y obtener documentación y pruebas.
  3. Confirmar autorización para asignar evaluaciones e importar resultados, versiones y baremos.
  4. Acordar el tratamiento de datos antes de enviar información de pacientes.

La preparación no descarga tests, copia baremos ni envía datos clínicos. Condiciones del proveedor.

Para continuar

Faltan las especificaciones de API y el acceso de pruebas de los proveedores. Con ellos se podrán implementar los contratos reales y comprobarlos por consultorio.
